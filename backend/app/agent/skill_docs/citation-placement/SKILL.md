# 该引未引怎么查

## 先分清：哪三类句子必须有引用

1. **他人的观点、判断、结论**。只要这句话的主语是「某某认为 / 研究表明 / 有学者提出」，
   或者你从文献里读来的解释框架，就必须给出处。判据：把作者名去掉后，这句话仍然像
   「别人说的」，而不是你从数据里直接看出来的。
2. **具体数据与事实**。样本量、比例、年份、政策条款、实验参数、价格、排名，
   凡是能被别人核对到某个来源的数字，都要标。判据：这个数不是你算出来的，
   也不是本文新测的，就要有来源。
3. **方法与工具的来源**。用了别人的量表、算法、模型、试剂、软件版本、
   编码框架，第一次出现时标一次；改动了原方法要在括号里说明「本文有修改」。

## 哪三类不必标

1. **自己的观察与本文数据**。你自己访谈、测量、统计出来的结果，写「本文调查了……」
   即可，不需要假装有文献支撑；但要在方法节交代怎么得到的。
2. **公理、定义与常识**。勾股定理、pH 的定义、「水在标准大气压下 100 ℃ 沸腾」
   这类教科书内容不必引；**边界是**：同行可能追问「谁说的」时，就不算常识。
3. **本文的新结论**。讨论节里由本文结果推出来的判断，属自己的贡献，不要挂别人的文献；
   若借用了别人的推理链，只给那一段推理的出处。

## 标「[n]」的具体做法

- 用顺序编码制：按正文**第一次出现**的顺序编号，同一文献重复出现沿用原号，
  不重复编号；文后参考文献表按号排列，正文与文后一一对应。
- 位置放在**被引内容之后、句末标点之前**；引一整句放句号前，只引一个词放词后。
  例：「该结论与已有研究一致[n]。」不要写成「[n]该结论……」。
- 一句里引多篇写 `[3,5]` 或 `[3-5]`；不要用 `[3][5]` 这种占两格又不清楚的写法。
- 直接引语要同时给页码：`[4]p.27`；转述不必给页码，但编号不能省。
- 编号只标在**真正支撑这句话**的位置。一段末尾挂一个 `[n]` 却支撑不了整段，等于没标。

## 发现「该引未引」时怎么说

先定位，再定性，最后给可执行的下一步：

1. **定位**：指出是哪一句（引原句开头十个字左右），不要笼统说「全文引用不足」。
2. **定性**：说明它属于上面三类中的哪一类，为什么需要来源。
3. **给方向**：建议去查什么（作者、年份、期刊、关键词），或者建议改写成本文观察。
4. **如实说不知道**：如果手头资料里没有可支撑的文献，就写「此处缺引用，暂未找到合适来源」。
   **绝对不许编一条文献顶上**——编造的作者、年份、DOI 比缺引用严重得多，
   属于学术不端，而且用户一查就穿。
5. **不要用「一般认为」「研究表明」蒙混**：没有具体来源的模糊主语，本身就是该引未引的信号。

## 核对清单

- 每个「研究表明 / 有学者认为」后面有没有编号？
- 每个外部数字、量表名、算法名第一次出现时标了吗？
- 编号是否按首次出现顺序？文后表里能不能逐条对上？
- 有没有把本文结果标成别人的文献？
- 有没有为了凑引用，把不相关的文献挂在句末？

## 判据

一句话能否回答「这话是谁说的、在哪里说的」；答不上又属于前三类，就是该引未引；
答得上但编号指不到对应条目，就是标错。两种都要如实指出，不许补一条假文献。
