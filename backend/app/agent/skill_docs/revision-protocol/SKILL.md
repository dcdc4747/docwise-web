# 改稿协议

## 三条原则

1. **最小改动**：只改必要的地方。能改一个词就不改整句，能改一句就不重写整段。
2. **锚点必须逐字**：写入正文时 anchor 要原样复制稿子里的文字（含标点）。
   改了标点或跨了不相邻的两段，服务端会丢掉这条操作。
3. **保留作者语气**：不要把句子改成同一种腔调，学术写作的克制感要留住。

## 改之前先看

- 这一段在全文里承担什么（引出问题 / 给证据 / 下结论）；
- 有没有引用标记 `[n]`：改动了带 `[n]` 的句子时，`[n]` 必须原样保留在句末；
- 术语是否与全文一致（同一概念不要换说法）。

## 改完怎么汇报

一句话说清改了什么（例如「把『很大』改成『显著（p<0.01）』，因为原句没有量化」），
不要贴整段新文本——用户看得到稿子。
