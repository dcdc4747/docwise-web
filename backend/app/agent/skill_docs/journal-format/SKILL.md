# 投稿体例

## 中文期刊论文（GB/T 7714 顺序编码制）

篇首信息（**不是正文小节**）：题名、作者、单位、中文摘要（200–300 字）、关键词（3–8 个）、
中图分类号、英文题名、英文摘要与关键词。

正文：引言 → 材料与方法 → 结果与分析 → 讨论 → 结论 → 参考文献。

判据：

- 摘要里不出现文献引用编号；不写「本文首次」这类无法核实的说法；
- 结论 2–3 条，每条都能在结果里找到对应数字；
- 参考文献按正文出现顺序编号 `[1][2]`，文后一一对应，
  格式 `作者. 题名[J]. 刊名, 年, 卷(期): 页码.`。

## 英文期刊（APA 7）

Abstract（不超过 250 词，单段，无引用）→ Keywords（3–6 个）→ 正文（引言**不加节标题**）→
Method（Participants / Materials / Procedure）→ Results → Discussion → References。

判据：正文引用用 `(Author, 2020)`；
参考文献 `作者 (年份). 题名. 刊名, 卷(期), 页码. https://doi.org/…`；
统计量报 M、SD、p、effect size。

## IEEE 会议论文

Abstract（150–250 词，单段，无引用、无未定义缩写）→ Index Terms（**字母序** 3–5 个）→
I. Introduction → II. … → Conclusion（**单数**）→ Acknowledgment（**单数**）→ References。

判据：节号用罗马数字大写（I.、II.、III.），二级用 A.、B.；图题在**图下**、表题在**表上**；
参考文献 `[1] A. B. Author, "Title," Journal, vol. x, no. x, pp. xx–xx, Year.`。

## 常见错误（检查时优先看这几条）

1. 把「题名」当成正文的一节；
2. 中文期刊缺中图分类号或英文摘要；
3. IEEE 写 Conclusions / Acknowledgements（应为单数）；
4. 摘要里出现 `[1]`；
5. 参考文献与正文编号不对应、条数不一致。
