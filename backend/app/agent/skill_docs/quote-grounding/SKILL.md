# 引用与出处纪律

## 唯一允许的引用源

引用只能逐字复制 **`read_blocks` 返回的那串 text**。外文文献这一版通常是块级译文，
所以引用时要标「译」；中文文献就是原文。**不得回译、不得改标点、不得把相邻两块拼成一句。**

块编号只放进 source_block_ids 字段，**不要写进给用户看的句子里**
（界面会把它变成「第 X 页 ·『开头…』」）。正文里给出处时写页码或该段开头几个字。

## 三类写法，别混

1. 直引：加引号 + 逐字文本 + 出处；
2. 改写：不加引号，写成自己的话；**不标成引用**，但依据仍可在 source_block_ids 里给块；
3. 概括：明确说「这一段大意是……」，不复述细节。

反例：把改写加引号（读者会以为原文就这么写）；把直引改两个词
（引号内不再逐字，等于伪造）。

## 找不到出处怎么办

- 工具没返回 → 写「**出处未能定位**」，并说明查过什么（检索词、task_id）；
- 只有导读字段、没有块 → 写「来自导读，原句未定位」；
- **绝不编 block_id**。编一个不存在的编号，后端会剔掉，
  用户看到的是空出处，比没有出处更糟。

## 同一句在多处出现

同一句话可能在正文、摘要、图注、页眉重复。做法：

1. 把 `search_library` 的命中全部列出，不要只取第一条；
2. 说明重复情形（「同一句在摘要与结论各出现一次」）；
3. 选最贴近用户问题的一处作出处，其余作为「另见」；
4. 两处措辞略有不同时逐字给出差异，不要合并成一句。

## 核对清单（引用前逐条过）

- 引号内与 `read_blocks` 的 text 逐字一致？
- 数字、单位、否定词（not / 不 / 未）有没有抄错？
- 出处指向的块确实包含这句话？
- 一句话里混了原文与自己的解释？
- 引的是结论还是方法？别把方法句当结论引。

## 常见错误

1. 用常识补一句「原文没写但显然」的话，还挂了 block_id；
2. 用省略号把两段不相邻的话连起来，改变了原意；
3. 同一结论给三个块，其中两个只是出现关键词；
4. 页码靠块号猜——块号推不出页码，除非工具明确给了页；
5. 把译文当原文引，却不标「译」。

## 判据

引号内逐字可核；每个 block_id 都在工具返回里；找不到就明说找不到；
用户照着出处能回到那一句。
