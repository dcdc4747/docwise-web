# 摘要四句法

## 结构：目的—方法—结果—结论

摘要只回答四个问题，按顺序各写一句（长句可拆成两句，但四块不能少）：

1. **目的**：为什么做这项研究。写「针对……问题，本文……」，
   不要从学科大背景讲起，也不要复述题名。
2. **方法**：怎么做。交代数据/样本、关键方法或模型、时间范围；
   能用一句话说清就不要罗列步骤。
3. **结果**：得到了什么。给**带方向的数字**（升高/降低、相差多少、显著性），
   不要只写「效果良好」「有明显改善」。
4. **结论**：这意味着什么。写一条可被结果支撑的判断，不外推到数据没覆盖的范围。

四句之间是因果链：目的决定方法，方法产出结果，结果支撑结论。
任何一句抽掉，读者都会缺一块信息。

## 硬指标

- 中文摘要 **200–300 字**（含标点，按字符计）；英文摘要 **不超过 250 words**。
- **不引文献**：摘要里不出现 `[n]`、`(Author, 2020)` 这类标记；需要背景就用自己的话概括。
- **不写「首次」**：也不写「填补空白」「国内外领先」这类无法核实、也无法由本文证明的话。
- **数字与正文一致**：样本量、比例、显著性、误差范围必须和结果节逐字对得上；
  正文改了数字，摘要同步改。
- 不写本文没有做的东西；不把讨论节的推测写成结论。
- 英文摘要用一般过去时叙方法与结果，用一般现在时叙结论；不出现未定义缩写。

## 正例

> 针对高校图书馆电子资源利用率偏低的问题，本文以 12 所高校 2019—2023 年的借阅与访问日志
> 为样本，采用双重差分法评估为期一年的推广活动对资源使用的影响。结果显示，活动使人均
> 数据库访问量提高 23.6%（p<0.05），纸本借阅量下降 8.2%，馆际互借请求增加 11.4%。
> 据此认为，推广活动改变了资源使用结构，但尚未扩大整体阅读需求，后续应把评估周期延长
> 到两年以上。

四块齐全：问题、样本与方法、三个带方向的数字、有边界条件的结论；没有引用，没有「首次」。

## 反例

> 近年来，数字阅读受到广泛关注[1]，已成为图书馆服务创新的重要方向，本研究首次系统
> 探讨该问题。本文采用问卷调查法，发现推广活动效果良好，显著提升了资源利用率。
> 结论对高校图书馆具有重要参考价值，填补了国内外空白。

逐条对照违反了什么：

1. 出现 `[1]` → 违反「不引文献」；
2. 「首次」「填补空白」→ 违反「不写首次、不写无法核实的评价」；
3. 「效果良好」「显著提升」没有数字 → 违反「结果要给带方向的数字」；
4. 方法只有「问卷调查法」，没有样本、时间、对象 → 违反「方法交代数据/样本」；
5. 「重要参考价值」是自我评价，不是由结果支撑的结论 → 违反「结论可被结果支撑」。

## 改写流程

1. 从正文结果节抄出 2–3 个核心数字，确认单位和有效数字；
2. 按「目的—方法—结果—结论」各写一句，先不管字数；
3. 数字对账：摘要里每个数都能在正文原样找到；
4. 压到 200–300 字：先删形容词与背景铺垫，不删数字和结论边界；
5. 最后扫一遍禁用词：`[n]`、「首次」、「填补空白」、「领先」、「效果良好」。

## 判据

- 四块齐全，且顺序是目的—方法—结果—结论；
- 中文字数在 200–300，英文不超过 250 words；
- 全文没有引用标记，没有「首次」类说法；
- 每个数字都能在正文逐字核对上；
- 结论没有超出结果覆盖的范围。
