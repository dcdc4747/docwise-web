# 写作模板的依据（2026-10-19）

用户质疑「预设模板是不是离谱」，逐个核对后**确实有问题**，已按真实投稿规范重写。
这份文件记下每个体例的依据与边界，避免以后又凭印象改。

## 一、旧版错在哪

| 旧写法 | 实际规范 | 判定 |
|---|---|---|
| 「题名」作为正文的一节 | 题名是**篇首信息**，不参与小节编号 | 结构错位 |
| 只有一种 IMRaD | 不同体例差别很大（见下） | 没区分刊物 |
| 中文期刊缺 中图分类号 / 英文摘要 | 中文期刊通行要求（GB/T 7714 + 各刊格式） | 会被编辑退回 |
| 学位论文只有 6 节 | 还缺 中英文摘要 / 目录 / 致谢 / 附录 | 不完整 |

## 二、新体例与依据

### 1. 中文期刊论文（`tpl-journal`，GB/T 7714 顺序编码制）

章节：中文摘要 · 关键词 · 中图分类号 · 英文摘要与关键词 · 引言 · 材料与方法 · 结果与分析 · 讨论 · 结论 · 参考文献

依据：中文科技期刊通行的 GB/T 7714 参考文献著录规则（顺序编码制：正文按出现顺序编 `[1][2]`，
文后一一对应）＋ 中文期刊常见的"中英文摘要 + 关键词 + 中图分类号"篇首信息要求。
摘要 200–300 字是中文科技期刊的常见区间（各刊略有差异）。

### 2. 英文期刊论文（`tpl-en-journal`，APA 7 / IMRaD）

章节：Abstract · Keywords · Introduction · Method · Results · Discussion · Conclusion · References

依据 APA 7 的实证论文结构（作者—年份制）：**正文引言通常不加节标题**、
Abstract ≤250 词、Method 常分 Participants / Materials / Procedure、
参考文献用 `作者 (年份). 题名. 刊名, 卷(期), 页码. https://doi.org/…`。
参考：[APA Style 官方教学材料](https://apastyle.apa.org/instructional-aids/apa-style-research-assignment.pdf)。

### 3. IEEE 会议论文（`tpl-ieee`）

章节：Abstract · Index Terms · I. Introduction · II. Related Work · III. Method · IV. Experiments ·
V. Conclusion · Acknowledgment · References

依据 IEEE 会议模板的硬性约定：**Index Terms 按字母序、3–5 个**；节号用**罗马数字大写**（I.、II.…）；
结论一般写 **Conclusion**（不加 s）；致谢写 **Acknowledgment**（单数）；
图题在**图下**、表题在**表上**；参考文献 `[1] A. B. Author, "Title," Journal, vol. x, no. x, pp. xx–xx, Year.`。
参考：[IEEE 论文格式与样式指南（示例）](http://www.ewh.ieee.org/cmte/ias-esw/pdfs/2008styleguide.pdf)、
[IEEE 会议模板（示例）](https://www.iwssip.org/archive/2023/wp-content/uploads/2023/01/iwssip_template.pdf)。

### 4. 学位论文（中文，`tpl-thesis`）

章节：中文摘要 · Abstract · 目录 · 绪论 · 相关工作 · 方法 · 实验 · 结论与展望 · 参考文献 · 致谢 · 附录

依据国内学位论文格式规范的通行要求（各校细则不同）：中英文摘要对应、目录用标题样式自动生成、
绪论含研究背景/现状述评/研究内容/论文结构、结论与展望、GB/T 7714 参考文献、致谢（含基金编号）、附录。

### 5. 研究报告（`tpl-report`）

内部报告体例（问题 / 背景 / 方法 / 发现 / 建议），**不是投稿体例**，没有期刊格式要求。

## 三、边界（写进界面的那句）

模板只给 **章节结构与写作要点**，**不实现各刊版式**：

- 页边距、字号、行距、分栏、页眉页脚、图表样式 → 要用**目标期刊自己的 Word/LaTeX 模板**；
- 参考文献的**具体排版** → 我们按 CSL 排版（gb-t-7714 / apa / ieee 都在 bib 样式里），
  但"投稿系统的字段校验"（DOI、作者 ORCID、基金号格式）不做假承诺。

## 四、如果还要更细

下一步可做"按刊定制"：给每本目标期刊存一份 `{章节清单 + 摘要字数区间 + 参考文献样式 + 图表要求}`，
模板菜单按刊名选。这需要用户提供**具体刊名**——各刊细则差异太大，不能靠猜。
