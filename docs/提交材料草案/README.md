## 三条写进正文的口径（评审可直接引用）

1. **每条结论都能点回原文那一句** —— 同类工具管到文献级，我们管到句级；
2. **不写"数据不出本机"** —— 准确口径是「**服务自持 + 文献存本地**」（取字与 OCR 真本地；外文翻译 / 扫描件逐段翻译 / 导读问答四处仍调云端模型 API）；
3. **精档一律写成"已从界面撤下"**，界面只提供快 / 中两档 —— 这是撤过一次不实宣称之后立的规矩：**界面上每一个能力描述，都要能在代码里指出它对应的实现**。
