## 分层架构

```
前端 SPA（Vue3 + Naive UI，App.vue 单文件；PWA：manifest + 最小 SW，可装主屏/离线）
   │  fetch/EventSource 经 apiUrl()（绝对 API base，可配 VITE_API_BASE/?apiBase=）
   │  HEAD /api/tasks/{id}/files/{mono|dual}
   ▼
FastAPI（main.py：全部路由 + SSE；routers/ask.py 问答；CORS 白名单 DOCWISE_CORS_ORIGINS 可追加；/api/health 真检查）
   │  enqueue(task_id)；POST /api/tasks/{id}/ask → llm.answer_question（全量上下文 / FTS5 兜底）
   ▼
worker（TranslationWorker：单进程串行 + 行锁认领 + 线程池跑引擎 + 事件总线；心跳 + 周期扫表 + 单任务异常不杀循环）
   │  get_engine(tier).translate() 子进程
   ▼
engine/（可插拔：base 接口 → open_source 快档 / medium 中档 / registry 按档位选）
   ▼
SQLite（WAL + busy_timeout；tasks / task_history / task_blocks / task_understanding / task_blocks_fts[FTS5 trigram]）
   ▼
日志（logging_setup：data/logs/docwise.log，5MB 轮转 ×3；写不了文件自动降级为控制台）
```

## 模块依赖（Python import 拓扑）

```
配置/存储层：
  config.py ──► pydantic_settings（.env；含 DEEPSEEK_* 与 DOCWISE_ENGINE_*）
  db.py     ──► config；SQLAlchemy engine/session（get_db）；SQLite PRAGMA（WAL+busy_timeout）；ensure_fts 建 FTS5 表+触发器
  models.py ──► db；engine.base.BlockState   # Task / TaskHistory / TaskBlock
  deps.py   ──► config/db  # 集中依赖注入：get_db（再导出）/get_settings
  logging_setup.py ──► config  # 根日志：轮转文件 + 控制台（写不了文件自动降级）
引擎层：
  base.py        ──► stdlib   ABC TranslationEngine + TranslateRequest/TranslationResult + 状态枚举
  open_source.py ──► base      # 快档：subprocess 调外部翻译脚本 → result.json
  medium.py      ──► open_source  # 中档：继承快档、换 DOCWISE_ENGINE_MEDIUM_* 前缀
  registry.py    ──► base/open_source/medium  # _ENGINES 按 Tier 选引擎；PRECISE 当前映射 medium
  __init__.py    ──► 以上全部，对外 re-export
worker/路由层：
  worker.py ──► db；engine；models   # 扫表恢复/行锁认领/线程池跑引擎/落库/发布事件
  main.py   ──► config；db；engine；models；worker；routers.ask   # 全部路由 + SSE + 建档；CORS 白名单可配
  llm.py    ──► config；httpx 调 DeepSeek：extract_understanding（导读/术语）+ answer_question（问答，block_id 出处）
  routers/ask.py ──► deps；llm；models   # POST /api/tasks/{id}/ask：全量上下文 ≤ 阈值；超阈值 FTS5（trigram）召回 + 2 字 LIKE 兜底；召不回诚实返回
前端：
  main.js  ──► App.vue；style.css；api.js（PROD 下注册 /sw.js）
  api.js   ──► API base 解析：?apiBase= > localStorage > VITE_API_BASE > 同源相对
  App.vue  ──► naive-ui 组件 + fetch/EventSource(apiUrl()) + HEAD(/files/*)
  public/  ──► manifest.webmanifest + sw.js + icons/（PWA：装主屏/全屏/离线壳）
```

## 核心数据流（上传 → 出稿 → 预览）

```
① POST /api/tasks/upload：存文件到 data/uploads/ → 建 Task(pending) → worker.enqueue 返回 202
② worker._loop：_claim(pending→in_progress,行锁,清旧块) → _load_request
      → get_engine(tier).translate()(线程池) → 引擎 subprocess→result.json(mono/dual+blocks)
      → _persist_result(写 TaskBlock + Task.status/progress/双路径) → bus.publish(completed/failed)
③ 前端 startProgress：EventSource /events → applyEvent(progress/status)
      → completed 后 checkPreview(HEAD files/mono|dual) → iframe / 下载
④ 获取结果：GET /files/{mono|dual}[?download]；历史 GET /api/tasks；详情 GET /api/tasks/{id}→blocks
⑤ 导读/术语：GET /api/tasks/{id}/understanding（取缓存/状态）；POST 同路径（惰性：未算则调 extract_understanding(带 block_id) 抽取并缓存，成功 ready、失败 failed）
⑥ 论文问答：POST /api/tasks/{id}/ask {question} → 总字符 ≤ docwise_ask_full_context_max_chars 走全量上下文；超阈值走 FTS5 trigram 召回 Top8（2 字词 LIKE 兜底）→ answer_question 按 block_id 引用；召不回/失败诚实返回，不编造
⑦ 运维（保命基建）：启动初始化日志 → 全链路打点（入队/开始/结束用时/失败堆栈）；worker 心跳 + 空闲每 30s 扫表兜底；GET /api/health 真检查（DB 写探测 + 心跳新鲜度 + 队列长度）
```

## 关键观察（改动时注意）

1. **LLM 只配置、零调用**：`config.py` 有 `deepseek_api_key/model/base_url`，但代码里没有任何 LLM 客户端调用 → M0/M1 才首次跑起来。
2. **路由组织**：`app/deps.py` 集中依赖注入（get_db 再导出 + get_settings）；M4 起新路由拆 `app/routers/`（ask.py 已入），旧路由仍在 main.py，渐进迁移。
3. **App.vue 是单文件巨组件**：先抽 composable（状态边界）再拆组件；用 `useTaskRunner`/`useTaskHistory`，**不装 Pinia**；再拆 `ReadingWorkbench`/`GuideTab`/`TermsTab`/`AskTab`/`HistoryList`。
4. **worker 单进程串行 + SQLite 单写者**：所有写库**收敛到一条写路径**；富化**不进 worker 任务状态机**（改惰性按需）；WAL 常开但**不背书并发写**。
5. **SSE 靠进程内事件总线（单进程）**：`worker` 与 SSE 端点共享 `app.state.event_bus`，**勿用 `--workers N` 多 worker**、**勿引入跨进程 pub/sub**（过度设计）；`understanding` 状态一律走 `GET /understanding` 派生，**不新增专用 SSE 事件**。
6. **precise 档当前映射 medium**（`registry.py` 里 `Tier.PRECISE: MediumEngine`），精细引擎未真正接入。
7. **无质量/回退/打回逻辑**：属后续阶段（2027），当前不加，答辩别吹。
8. **迁移**：保留 `create_all` + `_ensure_schema`（`PRAGMA table_info` + ALTER ADD 缺列），**不用 Alembic**；对真实存量库手测一次。
9. **不引入重基建**：**不建向量库/ChromaDB、不装 Pinia、不引入 Alembic、不引入 Capacitor**（用 PWA）——都是为"1 人现场答辩 + 9 月交稿"控成本。
10. **前端 API 调用一律走 `apiUrl()`**（`src/api.js`）：base 优先级 `?apiBase=` > localStorage（`docwise_api_base`）> `VITE_API_BASE` > 同源相对路径；手机连电脑后端用绝对 base，并在后端 `.env` 加 `DOCWISE_CORS_ORIGINS`（逗号分隔）放行手机页面来源。**SW 只缓存应用壳，`/api`、`/files` 直连不缓存**；新增后端路由不会被 SW 拦截。
11. **问答检索（M4）**：FTS5 用 **trigram** 分词器（unicode61 不拆 CJK，`实*` 零命中；trigram 最少 3 字符）——查询词 = ASCII≥3 字 + CJK 三字滑窗（去虚词）；2 字词（如"方法"）trigram 查不到，走 `translated/text LIKE %词%` 兜底；FTS 表每次启动 DROP+重建（rebuild 回填，容忍分词器/结构变更，开发库代价可忽略）。**问答不进 worker、不缓存、同步直调 LLM**。
12. **韧性约定（保命基建）**：① **单个任务的任何异常都不得杀死 worker 循环**（`_loop` 里 try/except + `_fail_safely`）；② 新增后台逻辑时要 `logger` 打点（入队/开始/结束用时/失败堆栈），**别再出现"出事没有记录"**；③ 健康检查必须**真验证**（现在会真写一次库并读 worker 心跳），不要写死返回 ok；④ `setup_logging()` 在 `main.py` 导入时调用一次（幂等），测试里也有覆盖。
