# 系统说明（草稿 · 2026-10-19）

> 用途：打包文件里的《运行说明 / 系统说明》；也用于赛项要求的"可运行版本 + 系统说明"。
> 面向读者：评审专家与想在本机跑起来的人。

## 一、系统组成

```
浏览器（Vue 3 单页应用）
   │  同一域名下的 /api/*（前端产物由后端挂载，不需要单独起前端服务）
   ▼
FastAPI 后端（单进程 uvicorn，内置后台 worker）
   ├── 业务库：SQLite（任务/块/导读/术语/草稿/引文/素材/记忆/版本）
   ├── AI 层：pydantic-ai 工具循环（场景 = 读懂 / 写作）
   └── 引擎层：子进程调用本地文档处理引擎（解析 / 翻译 / OCR / CSL 排版 / docx 导出）
```

**为什么把重活放子进程**：引擎依赖重（PDF 解析、本地 ONNX 识别、开源翻译引擎等），
后端本体只保留 6 个依赖（fastapi / python-multipart / uvicorn / sqlalchemy /
pydantic-settings / httpx），部署与"能不能打开"都更稳。

## 二、启动步骤（本机演示）

```powershell
# 1) 后端
cd docwise-web\backend
uv sync                                  # 首次
copy .env.example .env                   # 填 DEEPSEEK_API_KEY 与引擎路径
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 2) 前端（开发态才需要；正式演示直接构建一次）
cd docwise-web\frontend
bun install
bun run build                            # 产物 dist/ 由后端挂载
```

访问 `http://127.0.0.1:8000` 即可（同一地址同时提供页面与接口）。
局域网演示：`--host 0.0.0.0`，手机访问启动日志里打印的内网地址。

**依赖说明**

| 组件 | 版本/要求 | 备注 |
|---|---|---|
| Python | 3.12+ | 后端 + 引擎各一个 venv |
| Node/Bun | bun ≥1.1 | 只用于构建前端 |
| 引擎 venv | 由 `DOCWISE_ENGINE_PYTHON` 指定 | 需装 `python-docx`（Word 导出用）、PyMuPDF、ONNX 模型 |
| 数据库 | SQLite（自动建表） | 无外部服务 |

## 三、账号与权限

- 内置**演示账号**（用户名/密码见部署方配置），登录后可上传、阅读、写作；
- 所有任务接口都要 `Authorization: Bearer <令牌>`，并按归属过滤：**非本人一律 404**；
- 进度推送 / PDF 预览 / 下载用一次性**票据**（60 秒），因为这几类浏览器请求带不了请求头。

## 四、主要功能与入口

| 入口 | 路径 | 说明 |
|---|---|---|
| 我的论文（库） | `#/` | 上传、进度、历史、集合/标签/待读 |
| 读懂 | `#/read/{task_id}` | 段落精读 / 原版 / 纯中文 / 双语 + 右栏助手（问答·导读·术语） |
| 写作 | `#/write` | 正文编辑器 + 右栏（素材·对话·提纲·引用·过程·版本） |
| 校对 | 写作页右上「校对检查」 | 抽屉式报告，可导出 md/csv |
| 记忆 | 左侧导航「记忆」 | 术语/译名偏好、引用习惯 |
| 处理过程 | 左侧导航「处理过程」 | 本次会话的动作日志 |

## 五、一次典型使用（3 分钟走完）

1. 上传一篇 PDF → 等进度完成（扫描件自动走本地 OCR）；
2. 进「读懂」：看导读（研究问题/方法/结论，都带出处）→ 点出处高亮原文；
3. 在段落里选一句 → 「存为素材」；
4. 进「写作」：选「中文期刊论文」模板 → 写入骨架 →
   右栏「素材」插入引文 → 「对话」里说"把这节扩写成三句，直接写进正文" →
   正文自动写入（20 秒内可撤销）→ 「版本」里能看到每次保存；
5. 右上「校对检查」→ 看该引未引/格式问题 → 「导出 ▾」出 .docx。

## 六、健康检查与排障

| 现象 | 检查 |
|---|---|
| 打不开页面 | 是否先 `bun run build`；后端是否监听 8000 |
| 上传后一直 pending | worker 是否在跑（单进程，别用 `--workers N`） |
| 翻译/OCR 不动 | `.env` 里引擎路径是否有效；引擎 venv 是否能 `import` |
| 问答报错 | `DEEPSEEK_API_KEY` 是否有效；网络是否可达 API |
| Word 导出 503 | 引擎 venv 未装 `python-docx`（提示语会写清） |
| 时间显示差 8 小时 | 库里统一存 UTC，接口带时区；若见偏差检查 `app/timeutil.py` 是否被绕开 |

`GET /api/health` 会真查数据库与 worker，不只看进程活着。

## 七、隐私与合规（如实）

- 文献与稿件**存本地数据库与本地磁盘**；
- **翻译、导读生成、对话问答会调用云端大模型 API**（DeepSeek 等），因此不能宣称"数据不出本机"；
- 上传的文献请确保有使用权；导出物不含第三方受限内容。
