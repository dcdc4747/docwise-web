## 二、报名系统要填什么（逐项）

来源：[电脑版作品提交流程使用说明（2026-10-18 更新）](https://www.cmit.cn/uploadfile/2026/1018/45689.html)

**（一）基础信息**

- [ ] **参赛组别（必填）**：本科及以上学历赛道 / 高职高专赛道（按团队**最高学历**）
- [ ] **是否使用 AI 工具（必填）**：我们 **选「是」**，并如实填报使用环节
- [ ] **指导教师**（选填，最多 2 人）
- [ ] **参赛学生 1–5 人**（第 1 位是队长；可跨校）
- [ ] **学校**（必须从系统院校库选；不在库里发邮件 mail@cmit.cn 补录）
- [ ] **作品名称（必填）**——**还没定，这是最卡时间的一项**
- [ ] **作品分类（必填，单选）**：指定命题 / 自主命题 / 专项赛 —— 我们走**自主命题 → 移动与网络应用开发类**
- [ ] **作品简介、创意来源、运行环境（必填文本）**

**（二）上传材料**

| 栏目 | 是否必交 | 规格 |
|---|---|---|
| （6）参赛承诺书 | **必交** | 系统生成 → 下载 → **盖章** → 上传（1 个，图片或 PDF） |
| （7）作品截图 | **必交** | 1–10 张 |
| （8）作品评审视频 | 与（9）**至少一项** | 1 个，≤1 GB |
| （9）作品汇报 PPT | 与（8）**至少一项** | 1 个，≤200 MB |
| （10）参赛打包文件 | **必交** | ZIP/RAR/7Z，≤10 GB，**不能只放截图/视频/PPT** |
| （11）学生证 / 在校证明 | 仅国际专项赛 | — |

**提交动作**：点【提交审核】→ 状态变 **待管理审核** 才算提交成功（仍是"待提交审核"＝没提交）。

## 三、材料规范与 AI 披露（2026-10-15 新通知，最权威）

来源：[《材料提交规范》《AI 工具使用情况说明》发布通知](https://www.cmit.cn/html/tongzhigonggao/show-144-45835-1.html)

- [ ] 按《**参赛作品材料提交规范**》准备：承诺书 / 截图 / 成果文件 / 视频或 PPT / 打包文件
- [ ] **建议优先提交作品评审视频**（通知原文），PPT 作备选
- [ ] 视频分两种：**评审视频**（讲创新与实现过程）与**展示视频**（讲效果与交互），有其一即可
- [ ] **文字类材料建议 PDF**（作品介绍、运行说明、第三方资源说明、AI 使用补充说明）
- [ ] **专家评审材料要做匿名化处理**（去掉校名/人名/学号/公众号二维码等）
- [ ] 使用第三方代码/模型/数据/图片/字体/音视频 → 说明来源、用途、授权
- [ ] AI 使用说明按官方模板填：**工具名 / 使用环节 / 流程 / 提示词或工作流 / 人工筛选修改 / 学生原创贡献 / 版权与数据合规**
- [ ] 官网附件：
  - [材料提交规范（PDF）](https://www.cmit.cn/uploadfile/2026/1015/2026年第十四届全国大学生数字媒体科技作品及创意竞赛.pdf)
  - [AI 工具使用情况说明模板（DOCX）](https://www.cmit.cn/uploadfile/2026/1015/2026年第十四届全国大参赛团队数字媒体科技作品及创意竞赛人工智能工具使用情况说明.docx)

## 六、两条纪律（官网原文）

1. **AI 使用不直接加分也不扣分，但必须如实披露**；未如实披露 → 由专项工作组核查，可能取消资格/撤销奖项。
2. 作品须学生团队原创，不得抄袭套作；第三方素材须有授权并在材料中注明来源。
