## 二、怎么跑

```powershell
# 后端
cd docwise-web\backend
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m pytest -q

# 前端
cd docwise-web\frontend
bun run test
bun run build
```

CI（GitHub Actions）：`后端健康检查` + `前端渲染与构建检查`，推 PR 自动跑。

## 三、关键行为测试（挑最能说明"没造假"的）

### 3.1 出处可核对

| 用例 | 断言 |
|---|---|
| 编造出处被剔 | 模型给出不存在的块编号 → 接口返回的 `source_block_ids` 里没有它，且 `dropped_sources` 如实计数 |
| 只保留工具真返回的块 | 正则从工具结果里取块编号，答案里的编号必须在其中 |

### 3.2 AI 写入可控

| 用例 | 断言 |
|---|---|
| 锚点必须逐字存在 | `ops.anchor` 不在正文里 → 该条被剔除，`notes` 写明剔了几条 |
| 撤销 | 写入后 20 秒内点撤销 → 正文回到写入前的文本 |
| 版本留档 | 每次保存产生一版；回滚前自动再存一版（`source=restore`），所以回滚本身可回滚 |

### 3.3 富文本可持久

| 用例 | 断言 |
|---|---|
| 逐处字号 | 选中一段设 22px → 编辑器出现 `<span style="font-size: 22px">`；保存后 `body_html` 一致；**刷新后仍在** |
| 逐处字体 | 设楷体 → 同上（`font-family`），且工具栏回显正确 |
| 转换不丢样式 | HTML ⇄ Markdown 往返后内联样式仍在；`style` 里的双引号转义成 `&quot;`（否则属性被截断） |

### 3.4 界面结构（防回归）

| 用例 | 断言 |
|---|---|
| 助手页签互斥 | 同一时刻只有一个面板（素材/对话/提纲/引用/过程/版本）——这条是真出过 bug（两个面板叠在一起）后补的 |
| 三栏→两栏 | 素材并入助手后，只剩一条分隔条，正文宽度增加 |
| 流式渲染 | 生成中正文按节奏增长、步骤逐条入场；`MODE=test` 下关闭动画（**动画不该决定测试看到什么**） |

### 3.5 时间与编码这类"看不见的坑"

| 用例 | 断言 |
|---|---|
| 时间口径 | 库里统一 UTC + 接口带时区；`started_at - created_at` 应为秒级（曾差 8 小时） |
| 章节标题判级 | 5 篇真文献 64 条标题里错 5 条 → 补护栏后全库对账只变 6 块且全是纠正 |

## 四、手工端到端验证（浏览器真点，不是脚本）

| 场景 | 步骤 | 通过判据 |
|---|---|---|
| 上传 → 读懂 | 上传 PDF → 等完成 → 看导读 | 导读各项带出处；点出处高亮原文 |
| 读懂 → 素材 | 段落里选一句 → 存为素材 | 素材库出现该条，带「第 X 页 · 这一句开头」 |
| 写作 → 引文 | 打开草稿 → 插入引文 | 正文出现 `[1]`，「引用」页签同步出现该条 |
| 写作 → AI 写入 | 让助手"把这节扩写成三句" | 正文直接变化 + 提示"AI 已写进正文（1 处）撤销" |
| 撤销 | 点撤销 | 正文回到写入前 |
| 版本 | 打开「版本」页签 → 查看 → 回滚 | 列表有记录；回滚后版本数 +1（先留档） |
| 导出 | 导出 .docx / .md | 文件能打开，正文与参考文献都在 |
| 校对 | 点「校对检查」 | 三类分开显示；不自动改正文 |

## 五、已知限制（如实）

1. **TipTap 在 happy-dom 里跑不了**（需要真实 DOM 量测）→ 页面级用例用 textarea 替身；
   真编辑器行为靠浏览器实测（见第四节）。
2. **老稿子没有 `body_html`** → 打开时从 Markdown 转一份：内容不丢，但老稿没有"逐段字体字号"（那时没这能力）。
3. **扫描件没有版面坐标** → 判级退回文字形状，标题识别率低于文字层（已如实标注，不硬判）。
4. **模型输出有随机性** → 用例只断言"结构/校验/落地"，不断言具体措辞。
