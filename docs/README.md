# docs 目录索引

本目录放**长期有效**的项目文档；一次性的过程材料请放本地 `素材\`（不入库）。

| 文件 / 目录 | 用途 |
|---|---|
| `代码架构图.md` | **当前代码架构的权威快照**（分层 / 模块依赖 / 数据流 / 接入点 / 注意事项）。**改代码后必须同步更新本图**。 |
| `screenshots/` | 文档与 PR 用的界面截图（界面截图统一放这里，不要再散落到源码目录）。 |
| `验收/` | 各阶段的验收记录与截图（过程证据）。 |

## 约定

- **架构图是硬约定**：涉及模块 / 接口 / 数据结构 / 路由 / 引擎层 / 前端入口的改动，必须同步更新 `代码架构图.md`，方便后续人和 AI 快速理解底层。
- 提交前自查对外口径：**不出现参考项目真名、真实姓名，也不出现任何指向具体活动的字眼**（一律用中性词描述）。
- 大型样本、录屏、对比表格不走 git，放共享网盘/群；仓库只放文档与轻量截图。
