## 二、阈值是怎么定的（以及为什么不是别的数）

| 常量 | 值 | 依据 |
|---|---|---|
| 版面判标题的字号下限 | **1.20 倍** | 中文样本的真标题全是 1.20 倍（12.0/10.0）。**曾试过 1.25：`Keywords`（1.20、8 字）会被漏掉**——实测数字说话，抬阈值不能拍脑袋。 |
| 同一支的**长度上限** | **60 字符** | 真正能挡住冒牌货的是长度，不是阈值：EBSCO 那类 1.60 倍的"导语（deck）"是**一整句话**，而真标题都短（中文样本 2–8 字）。只用 1.25 挡不住 1.60，只会漏判。 |
| 上限（排除装饰） | **3.0 倍** | 实测 EBSCO 首页那个 8.95 倍的 `L` 是**首字下沉碎片**（单独成块），不是标题。 |
| 加粗支的带宽 | **0.85–1.15 倍** | 化学 arXiv 的章节标题**加粗但字号只有正文的 0.90 倍**（arXiv 惯例）——字号判据在那里方向是反的，所以加粗这支必须留。 |
| 加粗支要求全大写 | — | 实测 `Sheng Wu`（作者行，粗体 1.0、1.10 倍）会被这支吃掉；要求"全大写"把它挡在外面。 |
| 全大写行的长度/词数 | 45 / 4 | 实测作者署名行 `BY MADELINE COHEN, …`（58 字符）与页脚 `20AALLSPECTRUMIWWW.AALLNET.ORG` 会被"全大写"吃进来。 |
| 全大写行排除 CJK | — | **真 bug**：`str.isupper()` 对"CJK + 全大写拉丁"返回 True，`…生成式AI 驱动下` 整段被判成标题，一篇 257 块的文献误判出 **9 个正文段**。 |
| 题名区 | 首页前 **3** 块 | 实测真题名在**第三块**（22pt），前两块是 9pt 的页眉与引用行——按"第一块"判会把引用行当题名。 |
| 题名下限 | **1.15 倍** + 长度 ≥6 + 不像句子 + 不是图注 | 分别对应实测：不设倍数会把"整页都是正文"的文档硬吐一个题名；不设长度会让 1 个字符的碎片当选；不排除图注会让首页大字号图注抢走题名。 |

## 四、外文文献（引擎那条路）为什么判不出来

同一套规则在**引擎段落流**上几乎无效，原因不在规则，在**输入**：
- 实测化学 arXiv（182 块）中 `introduction / references / abstract / conclusion` 出现 **0 次**；
- 机制（见 `开源分析` 侧的 converter）：段落只在"类别切换或公式边界"处新建，标题与紧随的正文若被判成同一类，会**并进同一个段落、连分隔符都没有**；
- 所以**给块带上字号也补不回缺失的章节标题**（那是"改取块来源"或"前缀切分"的活），
  这条已写进路线：先做诊断（标题文本在不在段内），再决定走哪条。

## 六、引擎那条路的版面信号（2026-10-01，任务 3a）

### 录到了什么

引擎包装脚本（本地，不进公开仓库）在 `receive_layout` 那一帧读 `pstk`，按 **(页, 原文) 为键**
给每块写 `layout = {unit_h, y0, page_h}`（与文字层那条路同一个契约）。实测：

| 样本 | 页 | 块 | 带 layout | 录到批次 | 未录到 |
|---|---|---|---|---|---|
| 化学 arXiv（`chem_arXiv_2609.37896v1.pdf`） | 17 | 182 | **182/182** | 18 | 0 |
| EBSCO 杂志（`pdf_EBSCO_04.pdf`） | 5 | 42 | **42/42** | 5 | 0 |

### 回源核对（判据：页高偏差 >2% 算坐标系错）

- **页高：182/182 一致**（记录 792.0 = 源 PDF 页高 792.0，偏差 0%）；
- **位置**：抽样 20 块 **19/19** 命中；全篇 177 条可文本比对的块命中 **172 条**，
  剩下 5 条逐条人工定位后**全部落在 +1.5 ~ +2.2pt**，同样是下面那条固定口径差
  （不是错位：它们要么以公式开头、要么源 PDF 的行被拆成碎片）；
- **Δy（源 PDF 行顶 − 记录 y0）：中位 +2.15pt**（n=172，最大 2.82）——
  pdfminer 记的是**字体框顶**、PyMuPDF 给的是**行 bbox 顶**，同一坐标系里的**固定口径差**。
  契约里 `y0` 只用来算相对位置，不参与任何阈值判定，所以这个偏差无害——但要写下来，
  免得下次核对时把它当成 bug；
- **字号**：`unit_h` 不得小于首行字号的违规 **0 条**；"整块就是一行"的 19 块字号**完全相等**（±0.6pt）。

### 一个必须知道的口径差

`pstk[id].size` 是**段落内最大字号**（converter 里 `if child.size > pstk[-1].size` 会把它顶上去），
而文字层那条路取的是 **span 字号的中位数**。所以"标题 + 紧随正文"被并成一段时，
引擎记下来的是**标题**字号——块分级靠"大 **且短**"两条一起挡（整段正文都很长，过不了 60 字那关）。
**跨路只比同篇内的相对大小，绝不跨路比绝对值。**

  **这一条如实记下来**：它是"明显大 + 够短"判据的固有代价，视觉上它本来就是大字；
  语义上它不是章节标题，要真区分得靠版面类别（任务 A）。化学那份这一类误报 **0 条**。

### 为什么没有再放松/收紧阈值

化学那份带上 layout 之后**一个 heading 都没多出来** —— 因为它的标题要么被并进正文段
（段落长，过不了长度关）、要么被丢掉（压根不在块流里）。这正好说明**光有字号不够**，
阈值不该为此再动。**唯一改的三处判据都是真样本上抓到的错，不是"调参调出来的"**：

1. 署名行（缩写串）既不当 heading 也不当题名；
2. 题名区里**先筛掉不合格的、再取最大的**（首字下沉碎片 `L` 94.2pt 曾把真题名 47.4pt 顶掉）；
3. 图注编号后面紧跟**小写拉丁词**的是正文（`Fig. 7 shows…`），不是图注。

## 七、任务 A：外文标题为什么整段消失（2026-10-01）

上一节写"给块带上字号也补不回缺失的章节标题"——**方向对，根因找错了**。真根因不在
块分级、也不在版面信号，而在**解析阶段文本就没了**：

> 引擎默认的"公式字体"正则里有 `CM[^R]`——**CM 后面跟任何非 R 的字母都当公式字体**。
> LaTeX 排的文献里这条会误伤**文本**字体：`CMBX*`（Computer Modern Bold Extended＝
> 章节标题、论文题名）与 `CMTI*`（文本斜体）。被当成公式的字符**不会进段落文本栈**，
> 只留一个 `{vN}` 占位符；而纯公式段又不成块 → **标题整段消失**。

### 证据（不是推测）

- 字体清点（化学那份，按字符数）：被判为公式的**文本**字体有 `CMBX9` 976、`CMBX10` 374、
  `CMBX12` 53、`CMTI9` 666、`CMTI10` 76；真正的数学字体是 `CMMI*` / `CMSY*` / `CMEX*` /
  `MSBM*` / `CMMIB*` 那一族；
- **按位置核对**的基线：37 条粗体标题候选里，**0 条**是独立块。
  ⚠️ 第 0 步诊断当时报"19 条在段内"是**子串巧合**——182 块的文档里 `chiral measures`
  这种词组正文里必然出现，整篇文本一搜就有；换成"标题那一行的位置上有没有一个块"就归零了。
  **这个教训要记住：查召回必须锚定位置，不能全文子串搜。**

### 修法与 A/B（同一份 PDF、同一台机器，只差 `vfont` 一个参数）

修的是**引擎自己的开关**（`vfont`，非空时完全替换内置那条），判定收窄成数学字面白名单：

| 指标 | A 内置判据 | B 收窄判据 |
|---|---|---|
| 块数 | 182 | **212** |
| 公式占位符个数 | 840 | **730** |
| 标题位置上有独立块 | **0/37** | **26/37**（其余是多行标题的续行，已并进同一块） |

真跑一遍（走应用上传，任务 40）：**212 块**，类型 `{title 1, body 169, heading 30, caption 12}`
（修前是 `{body 174, caption 8}`、**一条 heading 都没有、连题名都没有**）。

### 版面区域（第三层）能加多少

区域类别**只贴标签、不切块**，坐标口径写死一处（origin 左上、y 向下、点），按"块首行
中心点落在哪个区域里"贴，多个区域取面积最小的（**双栏页必须带 x**，实测第 0 页
`I. INTRODUCTION` 在右栏 y≈297.9、左栏正文 y≈297.1）。

| | 化学 arXiv（212 块） | EBSCO（42 块） |
|---|---|---|
| 靠文字形状 + 字号认出的标题 | 21 | 1 |
| **只有区域才认得出来的真标题** | **9**（`II. ORIENTATION TRAJECTORY…`、`Appendix A~G`） | **5**（含题名第二行） |
| 只有区域才认得出来的真表注 | **2**（`TABLE I./II.` 罗马数字，文字规则只认阿拉伯数字） | 0 |
| 新增"正文 → 标题"误报 | **0** | 1（杂志导语，大字号导言，当标题可接受） |
| 因护栏没认出来的真标题 | 0 | 1（`What were the key takeaways…?` 以问号收尾，被"行尾不是句末标点"挡掉） |

护栏**沿用既有的两条，没有新增阈值**：不比 `_HEADING_MAX`（120）长、行尾不是句末标点。
