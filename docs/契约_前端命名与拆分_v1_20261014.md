## 2. 哈希路由（**不引 vue-router**）

⭐ **形态 §7 已定：左栏路由不引 vue-router**（后端运行时 6 依赖是红线，前端同理——**少一个依赖少一处风险**）。

| 路由 | 视图 | 期次 |
|---|---|---|
| `#/` 或空 | `LibraryView`（**我的库**，不再是 hero） | M0 |
| `#/read/:taskId` | `ReadView` | M0（承接现有 L2） |
| `#/write` | `WriteView` | M3 |
| `#/memory` | `MemoryView` | M7 |
| `#/process` | `ProcessView` | M5 |
| `#/me` | `MeView` | M5（含 ③④ 块） |
| `#/admin` | `AdminView` | 已有，接进来 |

### 2.1 `router.js` 的接口（**冻结，照这个签名写**）

```js
// 唯一的解析/序列化入口。别在组件里自己读 location.hash。
export function parseHash(hash)        // → { name: 'read', params: { taskId: 12 } } | { name: 'library', params: {} }
export function buildHash(name, params = {})   // → '#/read/12'
export function useRoute()             // → Ref<{name, params}>，内部监听 hashchange
export function navigate(name, params = {}, { replace = false } = {})  // 改 hash，触发一次 hashchange
```

**四条纪律**：
1. **`location.hash` 只在 `router.js` 里被读写一次**——组件里出现 `location.hash` 或 `window.onhashchange` 就是结构退化。
2. **未知 hash → 落到 `library`**，**不报错、不白屏**。
3. **`#/read/:taskId` 里的 taskId 必须校验**（非数字 / 非本人 → 走现有的"任务不存在"路径，**保持现有的 404 处理方式**）。
4. ⚠️ **不能因为引入路由而改变"回 L1 不清 currentTask"这条已有行为**——后台 SSE 要继续推（`App.vue` 现有注释里写明了这条，**别弄丢**）。

### 4.3 ⚠️ 五条容易做错的

1. **`--accent` 是"换值"不是"加变量"**——旧的 `#4f6ef7` 必须被替换。⚠️ **同时要改 `frontend/index.html` 的 `<meta name="theme-color">`**（现在还是 `#4f6ef7`），否则手机浏览器地址栏颜色与新设计不一致。
2. ⚠️ **旧强调色一共 12 处，其中 10 处是"硬编码的 rgba，不读变量"**——**这是最容易漏的地方**：

   | 位置 | 内容 |
   |---|---|
   | `style.css` L305–307 | **变量定义本身**（`--accent` / `--accent-soft` / `--accent-line`） |
   | `style.css` L71 | 登录页附近一处 `color: #4f6ef7` |
   | `style.css` L478–479 | **点出处后的高亮** `rgba(79,110,247,.28)` + `@keyframes flash` |
   | `style.css` L596 | 段落精读的高亮 |
   | `style.css` L763 / L767 / L771 | PDF 命中与高亮的三种深浅 |
   | `style.css` L787 | 段落 hover |

   ⚠️ **L478–479 / L596 / L767 / L771 就是产品的签名交互"点出处 → 高亮那一句"** ——**只换 `--accent` 变量、不换这几处硬编码，高亮会仍是旧蓝**，而它恰好是最显眼的地方。
   ✅ **做法**：把这几处 rgba 换成 `color-mix(in srgb, var(--accent) 28%, transparent)`，**或**追加一个 `--accent-flash` 变量（推荐后者：与 `--accent-line` 同一族，**改动面最小、可读**）。
3. ⚠️ **`--ok` / `--warn` 原色本身不过 AA 正文（3.51 / 3.19）——这是故意的**。它们**只做图标/边框/底色**；**文字一律走 `-ink`**。**不许"为了统一"把文字也改成原色。**
4. ⚠️ **`--fs-scale` 只乘阅读类字号**（正文、正文英文、译文）。**不乘界面字号**（按钮/导航/芯片不随阅读偏好变，否则布局会崩）。
5. ⚠️ **字体栈（`--font-sans`）与两个渲染开关（`-webkit-font-smoothing` / `text-rendering`）放最后一步**——**字体栈一改，全站字宽/换行/截断全变，会污染前面每一步的比对结果**（R1 明确要求从第 2 步挪到最后）。

## 7. 一件必须先决定的事（**待用户拍板，别自己定**）

**登录页 `LoginView.vue` 是全项目唯一大量使用 Naive UI 组件的地方**（`NTabs/NInput/NButton/NAlert`），其余是手写 `.dw` CSS。
**R1 已答：同意 B（照规范重写成手写）**，理由与风险 R1 都写了：
