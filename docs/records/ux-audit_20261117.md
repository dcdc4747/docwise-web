## 2. 逐模块评估

### 2.1 全局框架（导航 / 顶栏 / 状态栏）

**亮点（不要回退）**
- 左栏分「做什么 / 历史记录」两段，符合"动作"与"资产"分离的心智（`components/AppRail.vue:5`）。
- 收起后变 58px 图标态，给正文让宽度（`AppRail.vue:27`）。
- 底部常驻「本地优先 · 服务自持」——把数据口径写在界面上，是可信度设计。

**问题**
1. **品牌重复两遍**：左栏 `docwise / 文献工作台`，顶栏又写 `docwise · 学术文献理解智能体`。顶栏那行信息量极低，却占 40px。🟠 L2（截图 02-library）
2. **左栏下段贴底无分隔**：「记忆 / 处理过程」紧贴底部，与上段导航之间没有分隔线，视觉上像被裁掉。🟡 L2
3. **没有全局搜索**：11 篇时靠筛选还行，30 篇以上只能逐个翻。🟠 L1+L2（库页只有筛选条，`views/LibraryView.vue:15`）

**建议**：顶栏改成「页面标题 + 全局搜索 + 主操作」，品牌只留左栏；下段加一条 1px 分隔；搜索放在顶栏而不是筛选区。

### 2.2 文献库

**亮点**
- 空态、加载、错误三态齐全（`LibraryView.vue` 命中 空:7 载:3 错:1）。
- 筛选条件"没画出来的"会用一句话说明，不装死（`LibraryView.vue:28`）。
- 卡片上直接给「上次读到第 X 页」，是真正的回访理由。

**问题**
1. **文件名当标题**：两张卡都叫 `math_arXiv_2609.38101v1.pdf`，第一张还被断成 `...v1.` + `pdf`。🔴 L2（02-library）
2. **状态徽章折行**：「已完成」被挤成「已完 / 成」。🔴 L2
3. **筛选区 4 行常驻**，还包含 `手性方法 0`、`空集合 0` 这类零计数项。11 篇文献时，筛选取代了内容成为首屏主体。🟠 L2
4. **删除与主操作同权**：卡片右下 `开始阅读 / 详情 / 删除` 三个按钮同等样式。🟠 L2
5. **卡片高度不齐**：标题换行导致网格错位。🟡 L2

**建议**：标题用论文真实标题（首屏大字块已有），文件名降为副行；徽章 `white-space: nowrap`；筛选收成一行 `状态 ▾｜集合 ▾｜标签 ▾`，零计数隐藏；删除收进 `⋯`；卡片标题固定两行高。

### 2.3 段落精读

**亮点**
- 单栏后"一段原文 + 一段译文"连续读，对照关系成立（本次修复）。
- 目录可折叠、点一条滚到原文；阅读位置记忆。
- 出处锚点真的能落回原文（不是假链接）。

**问题**
1. **"AI 翻译"徽章逐段重复**：一屏出现十几次，噪声盖过内容。🟠 L2（03-reader）
2. **出处用机器编号**：问答面板直接显示 `p0_b2`、`p0_b7`、`p7_b103`。用户不知道 `p0` 是第 1 页、`b7` 是第 8 块。🟠 L2（ask 截图）
3. **顶栏 8 个元素挤一行**：返回 / 文件名 / 档位 / 视图 / 搜索 / 页数 / 下载 / 更多。🟠 L2
4. **作者行重复两遍**（同一串作者出现两次）：内容层问题，但用户会以为是渲染 bug。🟡 L2
5. 目录「31 节 展开」与左侧固定占 220px，正文被压到 ~700px。🟡 L2

**建议**：`AI 翻译` 改为页首一次说明 + 段落右上角一个小点；出处改成「第 3 页 · 第 2 段」；顶栏分两组（左侧导航、右侧操作），档位与视图合并进一个 `⋯`；作者去重。

### 2.4 问答 / 导读 / 术语

**亮点**
- 答案带可点击出处，且"出处可定位率 100% (9/9)"这种统计是诚实的自证。
- 支持"就这段提问"的锚点，问题与出处同一坐标系。

**问题**
1. **面板顶部两层头**：`问答 | 导读 | 术语` 一行，下面又有 `对话` + `轨迹·10` + `新对话` 一行。🟠 L2
2. **统计块抢注意力**："出处可定位率 / 本轮调用 5 次·模型请求 4 次"夹在答案与输入框之间，用户读的是答案，不是仪表盘。🟠 L2
3. **右栏太窄**：约 340px，长答案每行 12–15 字，滚动很长。🟠 L2
4. 示例问题 chips 常驻，占掉输入框上方空间。🟡 L2

**建议**：三层头合并为一行（页签 + 新对话）；统计折叠进"详情"；右栏可拖宽，或答案区改成"卡片 + 出处折叠"；示例问题只在首次进入时出现。

### 2.5 写作

**亮点**
- 20 秒撤销 + 版本回滚 + "AI 写正文需确认"，边界清楚。
- 模板只写标题不塞提示文字，克制。

**问题**
1. **"已同步"与"保存（禁用）"同时存在**：用户不知道到底存没存。🟠 L2（04-write）
2. **顶栏元素混排**：`天文 ▾`（选稿）/ `+ 新建` / `已同步` / `保存` / `校对检查` / `导出 ▾`——新建夹在稿件名和保存之间，语义断裂。🟠 L2
3. **编辑器工具栏两行**，缩进只有两个箭头图标无文字。🟡 L2
4. **右栏 6 个页签**（素材/对话/提纲/引用/过程/版本），每项两个字，密度高。🟡 L2
5. **状态栏写说明文**：底部"模板骨架与 AI 写入都可撤销…"是免责声明，字号极小。🟡 L1（`WriteView.vue` 底部）

**建议**：保存状态收敛成一个（"已保存 12:03"）；新建移到左侧草稿列表；工具栏第二行折叠为「更多」；右栏页签加分组（内容 / 过程）。

### 2.6 处理过程 / 台账

**亮点**
- 一条一条带时间、类型、数据流向（正文发往模型 API / 不出本机），这是同类产品少见的透明度。
- 顶部可按文献、层级筛选。

**问题**
1. **卡片留白过大**：一屏只能看 5–6 条，时间轴信息密度低。🟠 L2（ledger 截图）
2. **三个同级按钮**（导出 CSV / 导出 Markdown / 刷新）并排，主次不分。🟡 L2
3. **时间戳 + 类型 + 标签 + 模型名挤一行**，扫读困难。🟡 L2
4. 左栏高亮「处理过程」，页面大标题也是「处理过程」，重复。🟡 L2

**建议**：改成紧凑列表（时间 90px 固定列 + 类型 chip + 一行摘要）；导出合并为 `导出 ▾`；刷新降为图标。

### 2.7 个人中心

**亮点**
- 六个分区清晰：身份 / 账号安全 / 我的数据 / 台账 / 偏好 / 危险区。
- 危险区放最后且有说明。

**问题**
1. **单页太长**，没有锚点导航，找"偏好"要滚很久。🟠 L1（`MeView.vue` 6 个 section，570 行）
2. 台账与"处理过程"两处都在讲同一件事，入口分散。🟡 L1

**建议**：左侧加 6 项锚点；台账只保留一处（个人中心），处理过程页只做流水。

### 2.8 集合 / 标签 / 素材 / 回收站（仅 L1，无视觉证据）

- **集合**：527 行、15 个按钮，树形 + 智能集合同页，交互密度全站最高；建议拆「集合树」与「智能集合」两个页签。
- **标签**：80 行、2 个按钮，只能查看；**后端没有 DELETE**（只有 GET 与按名 upsert），界面上删不掉标签。🟠 L1+接口验证
- **素材**：148 行，功能最薄；空态靠模板内联，没有复用 `EmptyState.vue`。
- **回收站**：141 行，恢复 / 彻底删齐全；建议加"保留期限"说明。

## 5. Skill 反馈（回灌 `ux` 清单）

本次有两条可泛化的新规则，建议加进 `ux` 模块：

1. **机器标识不得直接呈现给用户**：`p0_b2`、`task_51`、UUID 这类内部 ID，必须翻译成"第 3 页 · 第 2 段"。❌ 例：本项目的出处芯片。
2. **同一语义状态只允许一个控件**：自动保存就不要同时有"保存"按钮；两者并存时用户无法判断哪个是真。❌ 例：写作页"已同步 + 保存"。
